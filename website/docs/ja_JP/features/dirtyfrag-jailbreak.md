# 内蔵 DirtyFrag 脱獄

MuSu Next 0.0.8 で**内蔵の DirtyFrag ワンタップ脱獄**が追加されました。CVE-2026-43284（ページキャッシュ書き込みの脆弱性）を利用して `dfroot.ko` を読み込み、**再起動すると消える一時的な root** を取得します。Bootloader のアンロックも、パーティションの書き換えも行いません。

これは研究向けの一時的な root であり、永続的な root ソリューションではありません。

## 入口

ホームページに常設の「脱獄」ボタンがあります。タップするとネイティブの脱獄画面が開きます（WebView なし、別のマネージャー不要）。画面は次の順に案内します：

1. **互換性検出** — カーネルが対応しているか確認します。
2. **リスクの説明** — 端末にどのような変更が及ぶかを列挙します。
3. **リスクの再確認** — 実行前に明示的に再度確認します。
4. **ワンタップ脱獄** — 一連の流れを一度で実行します。マネージャーの選択も外部マネージャーのインストールも不要です。

このペイロードが起動するマネージャーは MuSu Next のみです。マネージャーを選んだり、別途インストールしたりする必要はありません。

## 互換性

DirtyFrag は固定されたカーネルモジュールインターフェース（KMI）向けのペイロードを同梱しています：

- `android12-5.10`
- `android13-5.10`
- `android13-5.15`
- `android14-5.15`
- `android14-6.1`
- `android15-6.6`
- `android16-6.12`
- `android17-6.18`

KMI の一致はあくまで初期選別です。ベンダーが同じ KMI 文字列のまま修正をバックポートしている場合、KMI が一致しても脱獄できないことがあります。内蔵の検出が明確な判定を出し、非対応端末では脱獄ボタンが無効になります。

## リスク — タップする前に必ずお読みください

- **再起動すると root は消えます。** 権限は現在の起動中のみ有効です。再起動後は、再度この流れを実行するまで root はありません。
- **SELinux が permissive に設定されます。** ペイロードは `setenforce permissive` を実行するため、起動中ずっと端末は緩い SELinux 状態で動作します。
- **70 秒以内に二度タップしないでください。** 脆弱性の利用には約 70 秒の窓があります。その間の再タップや再起動はカーネルの競合を招き、フリーズや再起動につながる場合があります。実行中はボタンがロックされたままです。
- **失敗した場合はセーフモードで対処してください。** セーフモードで起動し、ペイロードを無効化またはアンインストールできます。

## ライセンスとソース

DirtyFrag ペイロードは**ランチャーアイコンのない独立 APK** として配布され、MuSu Next 本体の GPL-3.0-or-later コードとは独立した **GPL-2.0-only** ライセンスの下にあります。ソース：[MuSuNext-DirtyFrag](https://github.com/bilibiliHaoziyao/MuSuNext-DirtyFrag)。

## 制限

- これは**研究向けの一時的な root** であり、永続的な root ソリューションではありません。
- Bootloader のアンロックやパーティションの書き換えは行わず、再起動後も残りません。
- Play Integrity やサーバー側のリスク判定を通過できる保証はありません。各アプリが独自の検出ロジックを持っています。

## 他の機能との関係

- **環境チェック**：権限のないアプリが実際に何を見られるかを報告する独立した診断で、脱獄状態には依存しません。
- **Root アクセス監査**：アプリごとに Root の使用を記録します。脱獄は現在の起動中のみ root を付与し、監査はその間に実際に起きたアクセスを記録します。
