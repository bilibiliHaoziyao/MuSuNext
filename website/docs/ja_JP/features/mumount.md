# MuMount

MuMount は MuSu Next 内蔵のメタモジュールで、[Hybrid Mount](https://github.com/Hybrid-Mount/meta-hybrid_mount) をベースにしています。メタモジュールは他のすべてのモジュールファイルがシステムへマウントされる方法を引き継ぎ、既定方式よりも柔軟なマウント戦略（OverlayFS、Magic Mount、VFS）を提供します。

> MuMount は**既定で無効**です。有効化には**フル再起動**が必要です。

## 場所

MuZygisk と同様、MuMount も**モジュール一覧には表示されません**。「設定 → MuMount」を開いてください。管理画面は完全なネイティブ UI（WebUI ではありません）で、上部にマスタースイッチが一つあります。

## ステータス

| ステータス | 意味 | スイッチ |
|---|---|---|
| 無効 | 有効化しておらず、既定のマウント方式を使用 | 操作可 |
| 有効・再起動が必要 | オンにしており、次回起動時のマウント引き継ぎを待っている | 操作可 |
| 動作中 | マウントが有効で、成功・失敗したモジュール数を表示 | 操作可 |
| ブロック中 | 別のメタモジュールが既にインストールされている | グレーで無効 |
| 非対応 | カーネルが必要な overlay マウントに対応していない | グレーで無効 |

## 排他制御

MuMount は他のメタモジュールと共存できません。

- 他のメタモジュールがインストールされている場合、MuMount のスイッチは**グレー**になり、競合するメタモジュール名を表示して、無効化への導線を提供します。
- MuMount が有効な場合、他のメタモジュールは有効化できず、同様にブロックされます。

## 管理範囲

有効時、MuMount はモジュールファイルを同名のシステムファイルの上に重ねてマウントし、元のシステムファイルは変更しません。ステータス画面にはマウント範囲（`/system` / `/vendor` / `/product` など）、成功したモジュール数と失敗数を表示します。高度なマウント動作は設定ファイルで制御され、MuSu Next は初回有効化時にこれを生成し、以降はユーザーの編集を上書きしません。

MuMount は MuZygisk と同時に有効化できます——両者は独立しており、通知のみで競合とはみなされません。

## 有効化・無効化

1. 「設定 → MuMount」を開く。
2. 競合を確認し、必要なら先に解消する。
3. スイッチを切り替えて**フル再起動**を実行する。

無効化しても、マウント済みのモジュールファイルは次回再起動まで保持されます。

## Hybrid Mount との関係

MuMount は Hybrid Mount Developers による Hybrid Mount をベースにし、**GPL-3.0-only** のライセンスです。MuSu Next は上流のバイナリ・スクリプト・カーネルモジュールをそのまま同梱し、ユーザー向け名称と内部モジュール id のみを変更しています。詳細はペイロード内の `SOURCE.txt` と上流プロジェクトを参照してください。
