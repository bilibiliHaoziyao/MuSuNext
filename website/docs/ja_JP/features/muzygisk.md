# MuZygisk

MuZygisk は MuSu Next 内蔵の [Zygisk](https://github.com/topjohnwu/Magisk) 実装です。[ReZygisk](https://github.com/PerformanC/ReZygisk) をフォークし、MuSu Next 向けに再ビルド・改名したものです。別途 Zygisk プロバイダーを導入せずに Zygisk モジュールを利用できます。

> MuZygisk は**既定で無効**です。有効化には**フル再起動**が必要です。

## 場所

MuZygisk は**モジュール一覧には表示されません**。マネージャーの「設定」画面から「MuZygisk」を開いてください。管理画面は完全なネイティブ UI（WebUI ではありません）で、上部にマスタースイッチが一つあります。

## ステータス

| ステータス | 意味 | スイッチ |
|---|---|---|
| 無効 | 有効化しておらず、Zygisk 注入は動作していない | 操作可 |
| 有効・再起動が必要 | オンにしており、フル再起動後の反映を待っている | 操作可 |
| 動作中 | Zygisk デーモンが起動し、注入を行っている | 操作可（オフで無効化） |
| ブロック中 | 別の Zygisk 実装が既にインストールされている | グレーで無効 |
| ペイロードなし | このデバイスのアーキテクチャ用ビルドがない（例: riscv64） | グレーで無効 |

## 排他制御

MuZygisk は他の Zygisk 実装（Zygisk Next やカーネル内蔵 Zygisk など）と共存できません。

- 他の実装がインストールされている場合、MuZygisk のスイッチは**グレー**になり、競合するモジュール名を表示して、モジュール一覧で無効化への導線を提供します。
- MuZygisk が有効な場合、それらの実装はモジュール一覧から有効化できず、同様にスイッチがグレーになります。

これは厳格な排他です。二つの Zygisk 実装を同時に動かすと二重注入と起動失敗を招きます。

## 有効化・無効化

1. 「設定 → MuZygisk」を開く。
2. 上部のステータスカードを確認し、競合があれば先に解消する。
3. スイッチを切り替える。
4. **フル再起動**を実行する——ソフト再起動では Zygisk デーモンは再起動しません。

MuZygisk をオフにすると、デーモンと実行時ファイルは次回のフル再起動時に消去されます。
