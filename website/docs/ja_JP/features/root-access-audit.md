# Root アクセス監査

MuSu Next はマネージャーの下部バー中央に「セキュリティ」タブを追加しました。これは次の問いに答えるためのものです：**この端末で、誰が Root を使い、いつ、どれだけ使ったのか？**

生の SU ログを一行ずつ読む代わりに、セキュリティタブは散在するイベントをアプリごとに集計し、どのアプリが Root を頻繁に呼び出しているかをひと目で確認できます。

## 監査を有効にする

セキュリティタブを開くと、上部のステータスカードに監査のオン／オフが表示されます：

- **監査有効**：カーネルが Root 関連イベントを `sulog` ログファイルに書き込んでおり、下の統計が更新され続けます。
- **監査無効**：「監査を有効にする」をタップすると記録を開始します。

監査はカーネルの `sulog` イベントチャネルに依存します。有効化後に再起動は不要で、新しい Root リクエストからすぐに記録されます。

## アプリごとに見る

ステータスカードの下は「アプリ別」リストです。それぞれ Root リクエストを行ったアプリを表し、次を表示します：

- **アプリ識別**：プロセスの `comm`（または実行ファイル名 `exe`）
- **呼び出し回数**：そのアプリが発行した Root イベントの累計
- **最終呼び出し時刻**：最後のリクエストのタイムスタンプ
- **イベント種別タグ**：種類ごとの内訳
  - `root_execve`：Root コンテキストでコマンドを実行
  - `sucompat`：`su` 互換呼び出し
  - `ioctl_grant_root`：ioctl による Root 付与

リストは呼び出し回数の多い順に並び、よく使う Root アプリが上部に表示されます。ページを開くと自動更新され、手動でプルダウン更新もできます。

## 個別の記録を見る

呼び出しごとの原文（完全なコマンドライン、タイムスタンプなど）を確認したい場合は、リスト下部の「SU ログをすべて見る」をタップしてください。ログページでは種類による絞り込みと検索に対応しています。

## 他の機能との関係

- **App Profile**：各アプリの Root 権限範囲を制限します。セキュリティタブは実際に起きたアクセスを記録するため、両者を組み合わせて「権限付与＋記録」ができます。
- **SU ログ**：セキュリティタブの集計は同じ `sulog` データから得ており、ログページで元の記録を確認・削除できます。

## Root を一時的に止めたい？

セキュリティタブは「事後の監査」です。すでに起きたアクセスを記録します。銀行アプリやゲームのアンチチートなど、特定の場面で Root をブロックしたい場合は、モジュールをアンインストールするのではなく、App Profile で対象アプリの権限を取り消してください。
