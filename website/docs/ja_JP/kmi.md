# カーネルモジュールの照合

MuSu Next は LKM 方式なので、モジュールはカーネルの KMI と一致しないと読み込まれません。まず自分の端末がどれに当たるかを調べ、書き込み時にマネージャーで同じ項目を選んでください。

<KmiLookup lang="ja_JP" />

## カーネルバージョンの確認

adb かターミナルエミュレータで実行します。

```sh
uname -r
```

出力は `5.10.198-android12-9-g9a1b2c3d` のような形になります。そのまま上に貼り付けてください。

## 見つかったら

モジュールはマネージャーに内蔵されているので、別途ダウンロードする必要はありません。boot イメージを選んで「次へ」を押し、表示された KMI の一覧から上で調べた値を選びます。一覧には「このデバイスの KMI」が表示されますが、別の端末の boot を書き込む場合はその boot のバージョンを優先してください。

モジュールはカーネル ABI に対してビルドされているため、同じ KMI の端末なら概ね共通で使えます。カスタムカーネルを入れている場合、バージョンが一覧から外れることがあります。その場合はソースからビルドしてください。

書き込み手順は[インストール](./guide/installation)を参照してください。
