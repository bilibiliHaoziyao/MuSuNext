# 署名の検証

Root ツールは再パッケージされて公式を装うことがあります。APK を下のエリアにドロップすると、ブラウザが署名証明書の指紋を読み取り、公式の値と比較します。

処理はすべてローカルで完結し、ファイルがどこかに送信されることはありません。

<SignatureCheck lang="ja_JP" />

## 公式の指紋

```
eeed9504acee1543f84e57916ef50f88b69bc9abbc72fc80f803a42267a5ead0
```

カーネルが `KSU_EXPECTED_HASH` として照合している値と同じです。マネージャーがカーネルに認識される根拠がこれです。

## 一致しない場合

公式鍵で署名されていません。配布元が差し替えられたか、誰かが自分でビルドしたものかのどちらかです。前者は入れないでください。後者は配布元が信頼できるか自分で判断してください。

## コマンドラインでの確認

```sh
apksigner verify --print-certs your.apk
```

出力の `SHA-256 digest` が上記の指紋です。
