# 内置 DirtyFrag 一键越狱

MuSu Next 0.0.8 新增内置 **DirtyFrag 一键越狱**。它利用 CVE-2026-43284 页面缓存写入漏洞加载 `dfroot.ko`，获得**重启即失效的临时 root**；不解锁 Bootloader，也不刷写任何分区。

这是用于研究的临时 root，不是永久 root 方案。

## 从哪里进入

首页常驻「越狱」按钮，点开即进入原生越狱界面（无 WebView，无需另装管理器）。界面依次引导：

1. **兼容性检测**——判断当前内核是否受支持。
2. **风险说明**——列出越狱会给设备带来哪些改变。
3. **风险二次确认**——真正执行前再次明确确认。
4. **一键越狱**——一次跑完整个流程，无需选择管理器，也无需另装外部管理器。

该载荷只启动 MuSu Next 作为管理器，不用你挑管理器，也不用额外侧载。

## 兼容性

DirtyFrag 只为一组固定的内核模块接口（KMI）提供载荷：

- `android12-5.10`
- `android13-5.10`
- `android13-5.15`
- `android14-5.15`
- `android14-6.1`
- `android15-6.6`
- `android16-6.12`
- `android17-6.18`

KMI 匹配只是初筛。厂商可能在保留相同 KMI 字符串的情况下回移了修复，所以即便 KMI 匹配，设备也可能无法越狱。内置检测会给出明确结论；若设备不受支持，「一键越狱」按钮不可用。

## 风险——点之前务必读完

- **重启后 root 完全消失。** 授权只在本次开机内有效，重启后需要重新跑一遍流程才会再有 root。
- **SELinux 会被置为 permissive。** 载荷会执行 `setenforce permissive`，整个开机周期内设备都处于宽松的 SELinux 状态。
- **70 秒内绝不要重复点击。** 漏洞利用窗口约 70 秒，期间重复点击（或重启）可能引发内核冲突，导致卡死或重启。执行过程中按钮保持锁定。
- **失败时进入安全模式处理。** 开机进入安全模式，即可关闭或卸载该载荷。

## 许可证与源码

DirtyFrag 载荷以**独立 APK 分发、无桌面图标**，采用独立的 **GPL-2.0-only** 许可，与 MuSu Next 本体的 GPL-3.0-or-later 代码相互独立。源码：[MuSuNext-DirtyFrag](https://github.com/bilibiliHaoziyao/MuSuNext-DirtyFrag)。

## 限制

- 这是**研究用途的临时 root**，不是永久 root 方案。
- 不解锁 Bootloader、不刷写分区，也无法在重启后保留。
- 不保证通过 Play Integrity 或任何服务端风控，各家应用有自己的私有检测逻辑。

## 与其他功能的关系

- **环境检测**：报告一个未授权应用实际能看到什么，是独立诊断，不依赖越狱状态。
- **Root 访问审计**：按应用记录 Root 使用情况。越狱只在本次开机授予 root，审计会记录期间实际发生的访问。
