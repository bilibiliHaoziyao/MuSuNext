# 快照备份与恢复

> 自 0.0.7 起提供。原生界面，非 WebView。

快照用于备份你的环境配置，方便在换机或刷机后一键恢复——不必重新找回每个模块、逐个重新授权。

## 包含内容

| 项目 | 说明 |
|---|---|
| 模块 | 每个已安装模块的 id 与启用/禁用状态 |
| Root 授权 | 所有应用配置（uid、allow_su、gid/groups、SELinux 上下文） |
| 内建组件 | MuZygisk / MuMount 的开关状态 |

快照**不包含**模块 zip、应用数据或系统镜像，只记录配置状态。恢复要生效，模块必须已经安装。

## 在哪里

**「设置」→「备份与恢复」**（部分版本在「安全」Tab 入口里）。

- **创建**：在 `/data/adb/ksu/snapshot/` 下生成 `snapshot-<时间戳>.tar.gz`，内含记录各项数量与大小的清单。
- **列表**：显示每个快照的时间、模块/授权/组件数量与大小。
- **恢复**：应用所选快照的状态。
- **删除**：移除快照文件。

## 恢复是破坏性操作——请谨慎

每次恢复前，MuSu 会**自动为当前状态创建一份 `.pre-restore` 快照**，便于回滚。界面会二次确认，并写明将覆盖哪些内容：

- 模块的启用/禁用状态
- 整个 root 授权名单
- MuZygisk / MuMount 开关

恢复成功后会提示需要**完整重启**——模块挂载状态与 root 配置只在开机时完整生效。

## 典型流程

1. 刷机或换机前：**创建**快照。
2. 新环境装好同款模块后：**恢复**快照。
3. 完整重启，核对模块状态与应用授权。
4. 如有问题，恢复 `.pre-restore` 快照回滚。
