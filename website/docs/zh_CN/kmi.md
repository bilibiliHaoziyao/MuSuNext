# 内核模块匹配

MuSu Next 走 LKM 路线，模块必须和内核的 KMI 对上才能加载。先查清你的设备属于哪一档，刷入时在管理器里选同一档。

<KmiLookup lang="zh_CN" />

## 怎么拿到内核版本

在 adb 或终端模拟器里执行：

```sh
uname -r
```

输出类似 `5.10.198-android12-9-g9a1b2c3d`。整段粘到上面就行，不用自己挑。

## 对上之后

管理器已内置这些模块，不用单独下载。刷入时选好 boot 镜像，点「下一步」，在弹出的 KMI 列表里选这里查到的值。列表会标出「当前设备的 KMI」；但如果你刷的是另一台机器的 boot，以 boot 自身的版本为准。

模块按内核 ABI 编译，同一 KMI 的不同机型通常可以通用。如果你的设备刷了定制内核，版本号可能偏离列表，这种情况建议用源码自行编译。

刷入步骤见[安装说明](./guide/installation)。
