# 快照備份與還原

> 自 0.0.7 起提供。原生介面，非 WebView。

快照用於備份你的環境設定，方便在換機或刷機後一鍵還原——不必重新找回每個模組、逐個重新授權。

## 包含內容

| 項目 | 說明 |
|---|---|
| 模組 | 每個已安裝模組的 id 與啟用/停用狀態 |
| Root 授權 | 所有應用程式設定（uid、allow_su、gid/groups、SELinux 上下文） |
| 內建元件 | MuZygisk / MuMount 的開關狀態 |

快照**不包含**模組 zip、應用程式資料或系統映像，只記錄設定狀態。還原要生效，模組必須已經安裝。

## 在哪裡

**「設定」→「備份與還原」**（部分版本在「安全」分頁入口裡）。

- **建立**：在 `/data/adb/ksu/snapshot/` 下產生 `snapshot-<時間戳>.tar.gz`，內含記錄各項數量與大小的清單。
- **列表**：顯示每個快照的時間、模組/授權/元件數量與大小。
- **還原**：套用所選快照的狀態。
- **刪除**：移除快照檔案。

## 還原是破壞性操作——請謹慎

每次還原前，MuSu 會**自動為目前狀態建立一份 `.pre-restore` 快照**，便於回溯。介面會二次確認，並寫明將覆蓋哪些內容：

- 模組的啟用/停用狀態
- 整個 root 授權名單
- MuZygisk / MuMount 開關

還原成功後會提示需要**完整重新啟動**——模組掛載狀態與 root 設定只在開機時完整生效。

## 典型流程

1. 刷機或換機前：**建立**快照。
2. 新環境裝好同款模組後：**還原**快照。
3. 完整重新啟動，核對模組狀態與應用程式授權。
4. 如有問題，還原 `.pre-restore` 快照回溯。
