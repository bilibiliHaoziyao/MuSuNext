# 內核模組匹配

MuSu Next 走 LKM 路線，模組必須和內核的 KMI 對上才能載入。先查清你的裝置屬於哪一檔，刷入時在管理器裡選同一檔。

<KmiLookup lang="zh_TW" />

## 怎麼拿到內核版本

在 adb 或終端模擬器裡執行：

```sh
uname -r
```

輸出類似 `5.10.198-android12-9-g9a1b2c3d`。整段貼到上面就行，不用自己挑。

## 對上之後

管理器已內建這些模組，不用另外下載。刷入時選好 boot 映像，點「下一步」，在彈出的 KMI 清單裡選這裡查到的值。清單會標出「此裝置 KMI」；但如果你刷的是另一台機器的 boot，以 boot 自身的版本為準。

模組按內核 ABI 編譯，同一 KMI 的不同機型通常可以通用。如果你的裝置刷了定製內核，版本號可能偏離清單，這種情況建議用原始碼自行編譯。

刷入步驟見[安裝說明](./guide/installation)。
